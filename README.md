# Agents Workspace

A comprehensive workspace featuring specialized AI agent skills, configurations, and tools for software engineering, cloud development (Cloudflare, Workers, Durable Objects), frontend design, security auditing, testing, and modern full-stack frameworks (TanStack Start, Better Auth, Hono).

## Structure

- `.agents/skills/` - Specialized agent skills and domain knowledge bases.
- `opencode/` - Opencode configuration and agent settings.
- `skills-lock.json` - Locked dependencies and versions for workspace skills.
